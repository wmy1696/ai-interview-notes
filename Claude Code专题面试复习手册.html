Agent SDK 与 Subagents 的关系是什么？前者为后者提供了哪些不可替代的底层能力？

记忆线索SDK 是运行接口 / Subagent 是委派单元

口述答案 · 约 45–90 秒展开 / 收起

Agent SDK 把 Claude Code 的执行循环暴露为程序接口；Subagent 是在这个运行体系中执行独立子任务的代理。SDK 提供模型与工具循环、会话管理、权限、流式消息、Hook 和结果回传等基础能力。子代理在独立上下文里工作，主代理负责传入任务并整合结果。两者是基础设施与编排能力的关系。

追问与展开

工程展开：给子任务定义输入、允许工具、输出格式、预算和完成条件，再用日志追踪父子调用。

容易背错

“不可替代”只是该体系内的职责描述；其他框架也可以实现这些基础能力。

Q04已核对

Agent 的标准执行循环（Agent Loop）包含哪些关键阶段？各阶段的核心职责是什么？

记忆线索接收 → 决策 → 执行 → 观察 → 结束

口述答案 · 约 45–90 秒展开 / 收起

先接收目标与上下文，再由模型决定直接回答还是调用工具。运行时检查权限与参数后执行工具，把结果和错误反馈给模型，模型据此调整下一步。这个循环持续到完成任务、触发停止条件或达到预算。可靠闭环必须包含验证：运行成功只是工具完成，业务目标是否达成还要看测试或验收证据。

追问与展开

举例：修测试失败时，先复现错误，再读相关代码、修改、重跑测试；仍失败就进入下一轮。

容易背错

不要把一次模型请求等同于完整 Agent 任务，也不要漏掉失败反馈与终止条件。

Q08已核对

Channels 在 Claude Code 中的作用是什么？其与传统轮询式或新建会话式集成的核心区别何在？

记忆线索外部事件 → 已运行会话

口述答案 · 约 45–90 秒展开 / 收起

Channels 让外部事件通过支持通道能力的 MCP 服务推送进正在运行的 Claude Code 会话，例如消息或 webhook。相比定时轮询，它由事件到达触发；相比每次新建会话，它沿用现有会话上下文和任务状态。能否回复外部系统还取决于通道是否提供回复工具、权限及实际配置。

追问与展开

工程展开：处理重复事件要有事件 ID 和去重；明确允许的来源，避免陌生消息驱动工具执行。

容易背错

Channel 不是持久任务队列，也不能保证会话退出后仍持续处理事件。

Q17已核对

Claude Code Agent SDK 中，一个完整 agent loop 包含哪五个核心消息类型？它们各自承担什么语义角色？

记忆线索System / Assistant / User / Stream / Result

口述答案 · 约 45–90 秒展开 / 收起

五类核心消息是 SystemMessage、AssistantMessage、UserMessage、StreamEvent、ResultMessage。分别表示生命周期事件、模型回复与工具请求、输入或工具结果、可选的流式增量、运行结论与用量。UserMessage 不一定来自真人，工具结果也以该语义回传；StreamEvent 需要启用部分消息。

追问与展开

工程展开：按类型分流 UI、日志与状态；ResultMessage 检查 subtype，成功、预算上限和执行错误不能混为一谈。

容易背错

五类是核心分类，不是完整类型枚举；result 后仍可能有尾部事件，不宜无条件提前 break。

Q18已核对

Claude Code 的 Agent 执行循环如何设计与运行？各阶段职责及工具调用时机是什么？

记忆线索模型请求 / 运行时执行 / 结果驱动

任务开始时组装系统信息、历史和工具定义；模型输出文本或 tool_use。只有出现工具请求，运行时才在权限与 Hook 检查后执行工具，并把 tool_result 纳入下一次模型输入。模型根据结果决定继续、修正或结束。调用不是按预写脚本永远走同一路径，但权限与预算等边界由程序约束。

追问与展开

举例：找不到文件时应先搜索路径，而不是重复读取同一个错误路径；反馈应改变下一步决策。

不要说模型直接执行了 Shell；模型产生请求，执行由宿主工具层完成。

Q21已核对

Claude Code 的 agentic loop 包含哪三个核心阶段？这些阶段如何体现闭环反馈？

记忆线索收集上下文 → 行动 → 验证

口述答案 · 约 45–90 秒展开 / 收起

三个高层阶段是收集上下文、采取行动、验证结果。先读代码和错误定位问题，再修改或执行工具，最后用测试、构建或实际运行结果检验目标是否实现。验证发现问题后会重新收集信息并调整行动，所以这是一条可反复运行的反馈闭环，而不是输出一次代码就结束。

追问与展开

追问：与五阶段循环冲突吗？不冲突；三阶段是产品层概括，五阶段是消息与运行时过程拆分。

容易背错

验证必须有外部可观察信号；“模型觉得对了”不能替代测试通过。

高安全、多租户部署推荐什么边界模式保护凭证？怎样让凭证不暴露给 agent？
